# Replit AI Prompt — Phase 6: Market Memory Engine

## Objective

Act as a team consisting of:

* Senior Quantitative Researcher
* Institutional Market Analyst
* AI Memory Architect
* Machine Learning Engineer
* Data Architect
* Backend System Architect
* Financial Education Expert

Your task is to design and implement the **Market Memory Engine** for Market Language AI (MLAI).

The Market Memory Engine is responsible for giving the AI a historical understanding of the market.

It allows MLAI to remember:

* What happened before
* Why previous movements occurred
* Important price areas
* Historical reactions
* Market behavior patterns
* Previous decisions and outcomes

The AI should not analyze markets with short-term memory only.

It should understand the evolving story of the market.

---

# Core Philosophy

A professional trader does not look at one candle.

A professional trader remembers:

"Price has rejected this area three times."

"The last breakout from this zone failed."

"Buyers defended this level yesterday."

"Momentum has weakened compared with the previous move."

The Market Memory Engine creates this intelligence.

---

# Mission

Transform historical market events into meaningful memory.

The system should continuously build a market history timeline.

Instead of:

"Current candle is bullish."

The AI should understand:

"Buyers are attempting another advance after defending a support zone that previously caused two successful reversals."

---

# Memory Categories

The engine must maintain multiple types of memory.

---

# 1. Price Memory

Store important price events.

Examples:

* Major highs
* Major lows
* Swing points
* Previous breakout points
* Previous rejection areas
* Previous consolidation zones
* Historical support
* Historical resistance

Each memory should contain:

* Price level
* Time created
* Number of reactions
* Strength
* Current status
* Historical importance

# 2. Market Structure Memory

Remember structural events.

Examples:

* Beginning of trend
* Trend continuation
* Trend weakening
* Break of structure
* Change of character
* Range formation
* Accumulation
* Distribution

"The current uptrend started 120 candles ago after a confirmed structure change."

---

# Replay Mode Requirements

Memory must respect replay rules.

During replay:

Future events do not exist.

Memory is created only as candles appear.

The AI must not remember future support/resistance.

This prevents hindsight bias.
