# Replit AI Prompt — Phase 3.1: Design the Core Database for Market Language AI (MLAI)

## Objective

Act as a **Senior Database Architect**, **PostgreSQL Expert**, **Supabase Expert**, and **Enterprise Software Architect**.

Your task is **NOT** to generate application code.

Your task is to design the **complete Core Database Schema** for the Market Language AI (MLAI) platform.

The output should be a production-ready database architecture that is scalable, normalized, secure, and suitable for millions of users.

---

# Design Principles

* Use PostgreSQL (Supabase compatible).
* Follow Third Normal Form (3NF) unless a documented optimization justifies otherwise.
* Every table must have:

  * Primary key
  * Foreign keys
  * Constraints
  * Appropriate indexes
  * `created_at`
  * `updated_at`
  * Soft-delete support where appropriate (`deleted_at`)
* Use UUIDs for primary keys.
* Design for high read/write performance.
* Support horizontal scaling where possible.
* Avoid duplicate or redundant data.
* Document every relationship.

---

# Candle Data Requirements

The candle storage must support:

* Open
* High
* Low
* Close
* Volume
* Timestamp
* Symbol
* Timeframe
* Market
* Exchange
* Adjusted values if required
* Data quality flags
* Import source
* Versioning (if corrections occur)

Optimize for fast historical retrieval.

# Relationships

* One-to-One
* One-to-Many

Recommend indexes for:

# Constraints

Use:

* NOT NULL
* UNIQUE
* CHECK constraints
* ENUMs where appropriate
* Cascading rules only where safe
