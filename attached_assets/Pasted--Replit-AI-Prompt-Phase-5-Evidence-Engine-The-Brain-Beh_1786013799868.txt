# Replit AI Prompt — Phase 5: Evidence Engine (The Brain Behind Every Explanation)

## Objective

Act as a team consisting of:

* Institutional Trader
* Quantitative Researcher
* AI Reasoning Architect
* Data Scientist
* Financial Market Educator
* Software Architect
* Machine Learning Engineer
* Enterprise Backend Engineer

Your task is to design and implement the **Evidence Engine** for Market Language AI (MLAI).

The Evidence Engine is responsible for ensuring **every statement generated by the AI is backed by observable market evidence**.

The AI must never make unsupported claims.

---

# Core Philosophy

The AI must explain **why** it believes something.

Never allow the AI to simply say:

> Buyers are stronger.

Instead produce:

**Conclusion**

"Buyers currently appear stronger."

**Supporting Evidence**

* Higher High formed
* Higher Low maintained
* Strong bullish close
* Long lower wick rejection
* Resistance successfully broken
* Breakout held during retest
* Momentum increasing
* Volume confirms participation

Every conclusion must have traceable evidence.

---

# Mission

Transform raw chart information into structured evidence.

The Evidence Engine does **NOT** predict.

It collects facts.

The AI Interpreter consumes these facts to build explanations.

---

# Core Responsibilities

For every new candle:

1. Analyze chart state
2. Detect measurable events
3. Store evidence
4. Assign confidence
5. Group related evidence
6. Remove invalidated evidence
7. Pass evidence to the AI Interpreter

# Evidence Object

Every detected observation should be stored as a structured object.

Example:

```json
{
  "type": "HigherHigh",
  "category": "MarketStructure",
  "timeframe": "15m",
  "symbol": "XAUUSD",
  "timestamp": "...",
  "strength": 0.87,
  "confidence": 0.91,
  "source": "PriceAction",
  "status": "Active",
  "relatedEvidence": [
    "HigherLow",
    "BullishBreakout"
  ]
}
```

The implementation language and storage format are up to the system architecture, but every piece of evidence should carry equivalent information.

# Replay Compatibility

Replay mode must use only evidence available up to the current candle.

Never use future information.

Running the same replay multiple times should generate identical evidence.

---

# AI Integration

The Evidence Engine does not generate natural-language explanations.

It produces structured facts.

The AI Interpreter converts those facts into educational explanations.

This separation keeps the reasoning transparent and testable.

---

# Performance Requirements

The engine should support:

* Low-latency processing
* Incremental updates
* High-frequency candle streams
* Historical replay
* Millions of stored evidence records
* Efficient querying by symbol and timeframe

# Final Goal

The Evidence Engine should become the factual foundation of Market Language AI.

Every explanation produced anywhere in the platform should be traceable back to observable evidence.

The AI should never say **"I think."**

Instead, it should effectively communicate **"Here is the evidence, and this is the reasoning built upon it."**
